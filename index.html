About this gallery

An Instant In Eternity presents The Well Of Pure Source, Axpure as the centerpiece of this gallery. Additional pieces are loaded from images/manifest.json -- add an image file under images/ and one matching entry to that manifest to add a new piece to the gallery; there is no fixed limit on how many entries it can hold. The thumbnail grid below is a masonry layout (like Pinterest) that keeps each image's natural proportions, and pieces can be tagged for filtering as the collection grows. See the README for the exact format.
